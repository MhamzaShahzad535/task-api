# Task API

A simple CRUD API built with FastAPI.

## Description

This project is a small task management API.
It demonstrates the four CRUD operations:

- Create tasks
- Read tasks
- Update tasks
- Delete tasks

The API uses in-memory storage, so data resets when the server restarts.

## Technologies

- Python 3.10+
- FastAPI
- Uvicorn
